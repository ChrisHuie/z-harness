Locked 2026-07-11 (user). The identity frame that makes "notary not bank" CATEGORICAL, not case-by-case.

**Prebid is NOT a commercial entity and will NEVER transact for itself** — not as a buyer, seller, signals, or any agent role. Categorical difference from Scope3/Interchange: Scope3 is a commercial entity that transacts + tolls the flow, so it MUST be in the market (the source of its capture leverage + conflicts); Prebid is the structural opposite. You cannot be accused of self-dealing, participant/agency liability, or picking winners if you are CATEGORICALLY NEVER IN THE MARKET — strongest neutrality guarantee there is (not "we promise fairness" but "we structurally can't not be").

**STRUCTURAL TEETH (user 2026-07-11) — neutrality is enforced by GOVERNANCE, not policy:** (1) Prebid has a MULTI-COMPANY BOARD that would never let the foundation become a market participant — its own members (who'd be competing with their own foundation) block it; self-dealing is structurally impossible because the approvers are the parties it would harm. (2) NO same-person-run commercial entity — the precise structural INVERSE of AAO (neutral in FORM — Scope3-seeded board — but captured in STRUCTURE: the same person, BOK, drives the "neutral" org AND Interchange, the commercial toll). Prebid has no Interchange-equivalent to route value through. So the neutrality claim is VERIFIABLE (check the governance / org chart), not rhetorical — the strongest answer to the neutrality-integrity red-team worry and to any skeptic. HANDLING: the PUBLIC version is the positive statement about OUR structure ("Prebid's governance structurally guarantees it never participates"); the AAO same-person-commercial-arm CONTRAST stays INTERNAL (let the org charts speak; never a public accusation).

**AUTHOR, don't OPERATE.** We ship open-source, cross-platform REFERENCE agent implementations that other entities adopt + adapt for their own business/use-case (the Prebid.js model). We NEVER operate an agent as a commercial money-moving service — for ourselves OR on-behalf-of-others. Bright-line nuance: we CAN run reference agents in test / demo / the conformance sandbox (executing code ≠ transacting); the line is a COMMERCIAL money-moving service, and we never cross it.

**Universal across ALL agent roles** — buyer, seller, signals, creative, measurement (the AdCP domains). Each gets an open cross-platform reference. Others WILL build businesses on top (paid signal agents, managed buyer agents, etc.) — explicitly NOT our concern, focus, or competition. We author the commons; they build the economy on it.

**Mission: democratize the agentic market** — drop the barrier so anyone who wants to use / start using agents can, without passing through someone's app-store or paying a toll to exist. Prebid.js did this for header bidding; this is one layer up.

**Why it's load-bearing — it DISSOLVES a whole class of red-team findings at once:** every risk that began "…once Prebid becomes a market participant/operator" (buyer-agent agency liability; the operator-referee-legislator fusion's *operator* leg — the dangerous one — simply gone; market-integrity / receipt-abuse implicating us) assumed we're IN the flow. Author-not-operate removes us from it; what remains is exactly what Prebid.js does legitimately today (author spec + ship reference + run the open conformance checkmark — see [[project-agent-trust-layer]]). RESOLVES the red-team's issue-2 (buyer-agent inverted threat model): the buyer agent is fine as an open reference; the owed work is the SYMMETRIC buyer-side Gate/Commit + mandate-enforcement (budget / scope / rate / HITL — money stakes make it tighter than sell-side; model proposes, mechanism spends, mandate is the law); the bright line is author-not-operate.
