**Finding (verified 2026-07-11 from scope3.com + docs.interchange.io):** Scope3's headline product is "the Interchange for agent-to-agent advertising" (own domain: interchange.io). Their docs draw the line for us: *"The protocol [AdCP] handles discovery, negotiation, and execution. Interchange handles everything else... trust between counterparties, identity, billing, legal, observability, support."* They monetize with **a margin on all media that flows through** (built into media cost). => Scope3 is claiming the AUTHORITY / trust-root + settlement seat — the **bank** — monetized as a toll, while marketing AdCP as "no proprietary lock-in." The lock-in didn't vanish; **it moved up one layer, from the protocol to the Interchange.** Empirical proof of the single-camp-lock argument (POSITION §3.1, [[project-aamp-play]]).

**Two distinct Scope3 powers — treat separately.** (1) COMMERCIAL — Interchange as a clearing business; we can't/shouldn't try to kill it (unwinnable, off-premise, a turf war on their ground); we make it **optional & contestable** (a bank you can route around isn't a chokepoint). (2) STRUCTURAL — using AAO to govern the protocol, claim "neutral," and be the *mandatory* substrate; **this is the crutch and the dissolvable part.** So "dissolve Scope3's power" = strip the AAO crutch + make the bank optional — NOT kill their business.

**Mechanism (the Prebid.js / header-bidding move, one layer up — route around, don't ban):** commoditize every component of "bank" — issuance → open verifiable-credential mandates (anyone can issue → authority becomes a market, not a seat); verification → self-verifiable crypto, no phone-home (never have to ask the issuer "is this good?" — the question that makes a bank load-bearing); money path → substrate-native discovery + transact (the Interchange toll becomes one optional route, not the road); legitimacy → Prebid governance + the conformance flex ("ran our suite against their reference agent, it failed its own spec" = a withdrawal from AAO's neutrality account). The AAO crutch dies via `test_adcp_is_deletable` as an OFFENSIVE weapon (AdCP = one deletable face → AAO governs a replaceable edge, not "the protocol") + counter-legitimacy (Prebid is the more-credibly-neutral body: broad consortium, decade of neutral infra, the Aug-2025 TID win).

**Reconciliation with serve-anyone (locked, non-negotiable):** we dissolve concentration *by being universally neutral*, which REQUIRES serving Scope3 too. **De-capture through inclusion, not exclusion.** Lock Scope3 out and WE become the concentrator + hand them the "Prebid is capturing the layer" narrative. Radical neutrality is the weapon; the aggression lives in the STRUCTURE (open mechanisms), never the POSTURE.

**POSTURE — LOCKED (2026-07-11): structural-and-quiet.** We are genuinely neutral; Scope3 is welcome to participate; this is sensitive — handle delicately.

**HANDLING RULE (load-bearing):** neutral MECHANISMS go into public/shippable docs (POSITION etc.) on their own neutrality merits (own-mechanism-not-authority, notary-not-bank, VC mandates, origin-first discovery, conformance). The explicit Scope3/AAO-**dissolution MOTIVE** stays INTERNAL — memory + scratchpad only, NEVER in repo docs that could ship public. If a doc edit can't stand on neutrality alone, it doesn't go in.

**A1 consequence — three trust-handshake decisions hardened from preference → REQUIREMENT:** (1) **Mandate = verifiable-credential-shaped + phone-home-free** (a mandate verifiable without the issuer doesn't need the issuer to be a bank — THE anti-bank mechanism); (2) **discovery = origin-first** (`adagents.json`; denies the central-registry/Interchange discovery chokepoint; registry stays a supported adapter, never the default road); (3) **identity = push toward self-verifiable crypto** (weak AAMP bearer tokens grade `attested` and stay visibly second-class; every credential we verify ourselves is one Scope3 doesn't get to vouch for).

**Why:** the substrate-ownership thesis ([[project-substrate-ownership-strategy]]) isn't only defensive ("no protocol/org controls Prebid") — it now has a named agent-of-concentration: Scope3's Interchange is actively building the bank/authority seat and using AAO as a neutrality crutch. Naming the *mechanism* of de-capture (commoditize the bank's components) makes the thesis actionable.

**Authority-layer application (2026-07-13, from the authority-layer investigation):** keep authority where it legitimately belongs — the **AdCP world** (`adagents.json` = the sell-side authorization root, frozen + cosign-pinned; BIND it) and the **AAMP world** (their registry → `attested`); do NOT try to own what is rightly theirs. BUT guard against **AAO goal-intermingling** — the objects/outputs we AUTHOR stay under **Prebid's own neutral control** ("some things we need to control ourselves that we can"): the neutral `AuthorityAssertion` (`source × assurance`, **never a scalar verdict** — collapsing to a score is the act that would make us the root), the signed `Reading`/`SettlementEvidence`/`RateAuthority` (AdCP has **no object** for these — author now, bind frozen if IAB ratifies), and the verifier/certifier matrix. Bind the pinned `adagents.json` version + keep the **origin-key-as-tenant-root** abstraction so a schema-governance shift (who holds the pen — AdCP/Scope3-AAO vs an IAB liaison — is the strategically load-bearing unknown) can't strand us. Mechanism public (bind the legitimate roots, own the neutral layer); motive internal (guard AAO intermingling). Realizes the three A1 requirements above in the JOSE-COSE VC profile + origin-first `adagents.json` + the self-verifiable-crypto assurance ladder.
