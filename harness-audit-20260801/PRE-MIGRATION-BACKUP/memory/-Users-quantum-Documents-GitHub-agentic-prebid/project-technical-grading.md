**The model:** the grader **IS the egress-inert deterministic replay engine** (the money-kernel's replay machinery) pointed at a conformance corpus instead of a live deal's log — ONE engine, THREE faces (Sink Conformance Suite load-gate / protocol-agent grader / portability importer). **AdCP already ships the mechanical conformance corpus** (37 universal + 6 domain + 21 opt-in specialisms + the `runner-output-contract.yaml` per-requirement result-shape contract) and **explicitly refuses the verdict roll-up ("scoring weights/thresholds for a 'compliant' verdict" is a stated NON-GOAL)** → we BIND its mechanical layer, AUTHOR the 4 KINDs it lacks (money-safety I1–I15, durability/crash-resume, cross-protocol lossless, spec-version) + the ENTIRE AAMP corpus (none exists — "AAMP punts it, we complete it" again), and OWN the verdict seat (per-requirement, NO scalar — refuse-to-collapse, the [[project-authority-layer]] doctrine). Reproducibility = the money-kernel's record-and-replay: grade the DETERMINISTIC ENVELOPE over RECORDED model-I/O (the model is one `recorded_nondeterminism` member; the decide port is replay-intercepted); egress-inert (INV-9) = a grade fires no real payment/booking/model-call, and I1–I15 still run in shadow. Signed per-version report bound to `{agent_digest, corpus_hash, harness_version, spec_version, recorded_nondeterminism}` — the `adcp-tooling` `kernel.lock` discipline. Open-runnable harness (tool-not-service, CI per version). TWO modes: **drive-a-peer** (ships first, no sandbox) / **sandbox-execute** (later — the `SandboxProvider` port, Kata-on-Cloud-Hypervisor; consume [[project-agent-trust-layer]]).
