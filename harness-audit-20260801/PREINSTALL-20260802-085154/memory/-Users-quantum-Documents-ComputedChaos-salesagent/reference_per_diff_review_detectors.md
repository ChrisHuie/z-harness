`.claude/rules/private/detectors/` holds two families. The FRESHNESS family (run on every `adcp` bump via `bump_check.py`): `citation_freshness`, `fixme_format`, `recovery_audit`, `sdk_spec_drift` — see [[reference_harness_freshness_mechanisms]]. The PER-PR-DIFF family (run during review of a specific change; NOT in bump_check):

- **`disposition_ledger.py <artifact> [--notes <notes>]`** — reads a consolidation artifact; exits 1 on a finding with no resolved disposition, a missing Actions ledger, or "optional/non-gating" laundering a drop. `--notes` additionally diffs `path:line` citations in your notes vs the artifact and flags any that vanished (a within-finding site drop). Orchestrator/consolidation step. [[feedback_review_consolidation_drops_findings]]
- **`ssot_docstring_duplication.py [--base origin/main] [roots]`** — SSOT-CONTRADICTED: a "single source of truth"/"canonical" docstring whose symbol is defined in ≥2 files (`--base` marks the PR-relevant ones); DUP-HELPERS: underscore test helpers in ≥2 tests/ files; SSOT-CLAIMS-TO-VERIFY: unique canonical claims to trace for a shape-twin. Run by `review-code-patterns` (DRY) and `review-test-integrity` (test helpers). [[feedback_diff_scope_hides_duplicate_twin]]
- **`pr_import_cycle.py [--base origin/main] [pkg_root]`** — PAPERED-OVER cycles: a 2-module first-party cycle held together only by a lazy in-function import (hoisting it would ImportError); `--base` marks cycles involving changed files. Run by `review-code-patterns`. The inverted question a NEW cycle demands — relocate a leaf symbol vs defer the import — refines [[reference_lazy_imports_load_bearing]].
- **`suggestion_audit.py [--selftest]`** — the wire-VALUE sibling of `recovery_audit`, grounding buyer-facing `suggestion` text in the pinned `error-code.json` enumMetadata across BOTH emission surfaces: (A) module-level `*_SUGGESTION` constants (grounded by the code the NAME implies) AND (B) per-class `_default_suggestion` ClassVars, walking the `AdCPError` subclass tree exactly as `recovery_audit` walks `_default_recovery` — grounded against the enum for the class's ACTUAL wire code. Auditing only (A) is incidental: it catches a bad value only if it's a named constant and only if its name matches its code; surface (B) catches a `_default_suggestion` set to a bare literal no constant scan sees, and names every error class emitting a divergent hint (the blast radius). Flags CROSS-contamination (holds another code's canonical text — the drift class), DIVERGENCE (code in enum, text differs — drift or intentional), UNGROUNDED (no enum suggestion for the code), and NO-WIRE-ORACLE (grounded constant with no `wire == pinned_error_code_suggestion(code)` test — a future drift reaches the buyer with nothing red). Built after our own review missed a diverging `AUTH_REQUIRED` suggestion in the exact file we edited last — the constant-only cut would have caught it only by luck. Run by `review-error-wire`. [[feedback_wire_shape_change_systematic_sweep]]
- **`review_completeness.py <pr> [--since <iso|sha>] [--head <sha>]`** — the READINESS-GATE detector (per-PR review-STATE, not per-diff-code). Inventories all three GitHub surfaces + GraphQL review threads on the CURRENT head, newest-first, no author filter; exits 1 on activity newer than `--since` or an unresolved (not-outdated) thread. A moved live head past `--head` ALSO exits 1 and prints the unreviewed delta (commits + file-stat) — the head-advance re-audit (charter §4c precondition 6), added after a reviewer-requested "trivial" fold-in landed post-verdict and shipped an unreviewed wire-string change. Run by the ORCHESTRATOR immediately before ANY "ready/approve/meets-the-bar" verdict (charter §4c). Needs `gh`; may be absent in headless/cron runs. Built from the #1575 miss: a re-review said "meets the bar" after re-checking CI + prior findings but never re-pulling comments; a maintainer then posted 4 valid should-fix items on the same head. [[feedback_readiness_verdict_gate]]

All are WORKLISTS, not verdicts (the suite convention): heuristic, human adjudicates, self-test with `--selftest`. Each was built from a real miss a colleague caught after our review passed. When adding another, follow the disposition_ledger shape (rich docstring naming the miss-mode → pure `audit()` → `selftest()` → `main()` with exit 0/1/2) and wire it into the owning `review-*` agent's detection protocol, since [[MEMORY]] recall ≠ enforcement — the agent instruction is what makes it run.
