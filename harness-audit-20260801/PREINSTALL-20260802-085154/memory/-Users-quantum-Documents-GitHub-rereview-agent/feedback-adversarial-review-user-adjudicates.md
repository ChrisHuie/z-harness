The user (2026-07-24, during rereview-agent plan review): "i like this adversarial nature of review ideas, concepts, work... and then expanding from it. Me deciding what is relevant or good or not."

**Why:** Adversarial passes (drafter + attacker, measured refutation, multi-lens panels) surfaced falsified claims and real design gaps that consensus-style review missed — and the user wants to stay the arbiter of which findings matter rather than having them silently accepted or discarded.

**How to apply:** For substantive ideas, designs, and work products, default to adversarial structures: independent draft → adversarial verification (attack claims with measurement, not vibes) → expand from what survives. Present findings with severity, evidence, and a recommendation — then put acceptance/relevance decisions to the user (AskUserQuestion or explicit options) instead of auto-applying anything contestable.
