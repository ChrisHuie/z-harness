The discovery half of A1 — locked 2026-07-11, then grounded against primary sources (findings calibrated below).

**BIG VALIDATION — the decentralized primitive already exists and is AdCP's OWN stated architecture.** AdCP defines agent authorization as `/.well-known/adagents.json` on the PUBLISHER's own domain ("robots.txt for advertising"; lists `properties` + `authorized_agents`). The AAO registry is EXPLICITLY a cache/index over those decentralized files (open RFC: "AdCP Registry API for cached adagents.json lookup"). So "self-sovereign identity + registry-as-index-not-gatekeeper" isn't our invention — it's their spec. Our job = DEFEND AdCP's decentralized design against the drift that makes the cache-index de-facto load-bearing. Quieter + more defensible (hold them to their own spec).

**Our de-capture — design like the WEB, not an app store; "header bidding for agent discovery"** (Prebid did this once to Google's ad-server waterfall; do it again to a would-be registry gate). UNBUNDLE the 5:
- **Identity = self-sovereign** — publisher/agent's own domain + `/.well-known/` (or a DID). Root of authority is the domain, not the registry.
- **Capability = self-published, bind to FROZEN OBJECTS not the SDK.** AdCP family: `get_adcp_capabilities` (supported_protocols + specialisms) + `skill.md` + `adagents.json` + MCP tools (health/ask_about_capability/api_call). A2A family: the AgentCard at `/.well-known/agent-card.json`. One neutral internal `AgentDescriptor` DTO bridges BOTH families. Implement our OWN harness; don't depend on their TS SDK reference impl.
- **Findability = plural indexes.** `DiscoveryIndex` port (Prebid.js-adapter style, like BookingSink) = a neutral bridge ACROSS the fragmenting discovery standards (adagents.json ↔ Google ARD ↔ MIT NANDA ↔ A2A cards ↔ MCP registry), not just "our index vs theirs." We maintain the port + a removable Prebid reference index + a few; others' registries = READ adapters (interoperate, don't depend). Guard `test_registry_is_deletable`.
- **Authority = verifiable signed MANDATE** (adagents.json / VC) checked against the OPEN trust root, not "the registry says so." [[project-neutral-primitives-charter]] T3.
- **Trust = conformance + portable attestations, NOT membership.** Being-in-a-registry is NOT a trust signal.

**Distributed is the LAW. IAB ≠ the enemy** — IAB frozen objects = conform-to (T2 partner); the would-be registry/verified-gate is the fight. Never aim de-capture at IAB by accident.

**The neutral world is already moving our way (align + bridge, don't reinvent):** W3C DIDs v1.1 (2026 CR) + Verifiable Credentials; W3C Agent Identity Registry Protocol CG (launched 2026-04-24; DID-method-for-agents + VC agent creds; coordinates DIF / OpenID AIIM / IETF WIMSE); MIT Project NANDA ("DNS for agents"; signed AgentFacts; decentralized quilt-of-registries; cross-protocol); Google ARD (Apache-2.0, Linux Foundation AI Catalog WG; `ai-catalog.json` well-known; "registries act as search engines that crawl catalogs" = our web-not-app-store thesis, already standardizing); A2A (now Linux Foundation) + MCP registry (official but OPTIONAL over point-to-point). Prebid's seat = the neutral BRIDGE across these, the same role as AdCP↔AAMP.
