The three OTHER open reference agents beyond the two seats ([[project-two-seat-model]]), authored 2026-07-13 as `docs/design/reference-agents.md` (3 parallel grounding dives + a 3-lens adversarial red-team, held to money-path rigor). Repo is source of truth; this is a recall-pointer. Register: IR-49 (authored) + IR-50 (red-team) in `improvement-register.md`.

**Common frame — no third seat; three attachment archetypes.** The `Commitment` stays seat-symmetric buyer/seller only; signals/creative/measurement are PARTICIPANTS, never money principals (`payer/beneficiary ≠ SELF`). What differs is HOW each attaches: **W witness** (measurement → a signed `Reading` the kernel folds — the delivery-oracle producer generalized), **P invoked-port** (signals → `activate_signal` as a sink `do·verify·compensate` saga; the ad-server adapter-registry pattern on the data side; `deactivate` = forward compensator), **S shared-substrate+decide-port** (creative → the AuthPolicy edges the two seats operate + generation via the model-layer quarantine). An agent COMPOSES archetypes (creative is S + **P** once `build_creative(execute)` bills `vendor_cost`). Six invariant threads: assurance ladder gates bill/serve; fees disclosed-not-taken (INV-11, `FeeLine.beneficiary≠SELF`); independence; lethal-trifecta (acute for signals = audience data, creative = the brief); author-what's-punted (AdCP has **NO signed-measurement primitive** → our `Reading` IS it; AAMP has no priced-signal and no creative surface); L0-safe config. The ecosystem validates the split from outside: SalesAgent deliberately **removed its own signals tools** ("should come from dedicated signals agents"), AdCP 3.1 **discovers creative agents as invoked roles**.

**THE load-bearing red-team finding (reusable far beyond this doc): independence must be ECONOMIC, not CRYPTOGRAPHIC.** The money kernel is safe because the two seats are ADVERSARIES — opposed interests that check each other, so the kernel only has to prove neither can forge the OTHER's leg (F3/PC2 signer-pinning). The three participants are dangerous because a participant's interest can be ALIGNED (captured) with one seat by whoever **selects and pays** it. Key/ownership-disjointness (F3, PC2, and my naive first-pass `I16` witness-set rule) — which HELD — does **not** imply the interest-independence corroboration actually needs. Every CRITICAL/HIGH the 3 lenses found lives in that gap: a seller-**paid** verifier (issuer-pays / credit-rating-agency capture — F3-independent yet biased), a self-owned **FeeLine shell** (`≠SELF` passes because the shell's key isn't the party's — the disjointness doctrine never reached the money-RECEIVING edge → **RA-BENE, a new CRITICAL**), a model-steered paid activation/generation, a coverage figure the beneficiary **single-witnesses**. Fixes: `funded_by`/`selected_by` on `Reading` + **augment-never-arbitrate** (the PC1 mirror); **volume-independent** quorum-witness fees (never `percent_of_media`/`cpm` for a party that also witnesses the count); disjointness over the **deal-wide UNION of witnesses AND fee beneficiaries**. Much of the surface stays OPEN (price/coverage basis is N=1 self-claim; evidentiary independence — a resold/re-signed reading is two roots one observation; outcome seat-ASYMMETRY — conversions fire on the advertiser's property so the seller is blind, need a `degenerate_sell_leg`; cross-deal concentration/rotation; a capturable single MRC accreditation root) → **money-adjacent participant modes (activation, generation-execute, verification-fee, outcome settlement) are gated OFF until closed; L0 discovery-only / validate-only / self-attested-only is safe.** Honest claim stays "no wrong settle without a corroborated, attributable basis + full audit," never "fraud-proof."

**What HELD under all 3 lenses** (the solid core, now precisely delineated): INV-8 non-minting + the `≠SELF`/no-`Balance` custody bright line (every hole is a PARTY hiding/creating an edge, never the core taking custody); signature-pinning bars a model fabricating a billable impression COUNT (no key + the F1 N≥2 same-metric quorum); `Context.trusted` cross-DEAL minimization; the stacked-net ARITHMETIC (I15 freezes correctly-tagged seller-borne fees breaching floor); `operator_side`-from-principal. The architecture (no third seat; W/P/S) is sound; only the CORROBORATION layer built on top was overclaimed. Also caught + fixed: the three new ports (`SignalsPort.activate_signal`, `DeliveryReadingSource`, `build_creative` vendor call) were absent from the ML2 `is_shadow`/INV-9 replay set → replay would re-activate + re-bill (a real correctness bug).
