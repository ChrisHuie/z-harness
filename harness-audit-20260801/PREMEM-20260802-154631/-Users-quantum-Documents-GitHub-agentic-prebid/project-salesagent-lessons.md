**TYPED-BOUNDARIES PRINCIPLE — ADOPTED as a first-class rule** (harvest from salesagent PR #1044; `_legacy/.claude/notes/typed-boundaries-principle.md`): pydantic models are the universal INTERNAL representation; serialize to/from dict/JSON ONLY at system boundaries (serialize once, deserialize once); NO `model_dump()` between internal layers; **errors are typed response models too**; extension classes MINIMAL (extend the library types; the `2jl` `ConfigDict(extra=get_pydantic_extra_mode())` pattern — forbid-extras-in-dev / ignore-in-prod for forward-compat; deprecated-field normalizers as boundary pre-validators). "The boundary absorbs version differences; protocol changes don't break internals."

**ERROR-FIDELITY PRIMITIVE** (sharpens the charter's error-recovery-class engine — [[project-neutral-primitives-charter]]): the hard part is NOT the taxonomy — it's error QUALITY surviving the FastMCP / pydantic / A2A / REST boundaries (user's hard-won lesson; the taxonomy proliferation never actually bit — it was just consistency effort). ROOT CAUSE (salesagent `_legacy/.claude/notes/fastapi-unification-proposal.md`): "no shared application framework" — MCP(FastMCP `ToolError`) / A2A(~500 hand-rolled lines, errors as `{success:False}` DICTS not exceptions) / Flask(`abort()`) each reinvent error handling → 3 divergent serialization paths → fidelity leaks at the seams. THE FIX = our design by construction: ONE typed core + a transport SEAM IS the shared framework they lacked (they proposed unifying on FastAPI but, being 3 processes, couldn't). Error primitive = a TYPED error model `{ recovery_class (small/closed/ours: transient/correctable/terminal + retry-after) · cause (PRESERVED, typed-by-source: protocol / underlying-system / our-mechanism) · context (op/field/tenant/idempotency-key) }` with ONE lossless (de)serialization per transport adapter, guarded by `round-trip-or-raise` on EVERY transport. Collapse-for-ACTION, preserve-for-DESCRIPTION. Their roundtrip tests exist but are tied to `apply_testing_hooks()` and don't guard ERROR round-trip across transports = the gap OUR harness closes. AAMP has NO error taxonomy (≥3 ad-hoc envelopes, producer defines none → pass-through from the underlying system); AdCP over-specifies but the SDKs collapse it. So AAMP-over-core AND AdCP-over-core both carry errors BETTER than their own SDKs = "complete the protocol" both ways. [[project-transport-and-comms]]
