Goal: build a cross-harness "prompting engine" — author prompting content once, deploy it across coding-agent harnesses (Claude Code, OpenAI Codex, Gemini/Antigravity `agy`, Copilot, etc.), with configurable quality/style axes (accurate, articulate, concise, nuanced, explanative, narrative, defined) and a measurement loop.

Researched direction (2026-07-13, see repo `docs/research/2026-07-13-landscape.md` for sources):
- Canonical format = Agent Skills open standard (SKILL.md folders, agentskills.io) — natively read by 30+ tools as of mid-2026; portable dir is `.agents/skills/` but Claude Code only reads `.claude/skills/`, so a thin emit/sync layer bridges directories, frontmatter dialects, and always-on context files (AGENTS.md/CLAUDE.md/GEMINI.md).
- Differentiation vs prior art (rulesync, Ruler copy skills verbatim): model-aware rendering (Claude XML/no-emphasis-spam vs GPT-5.x literalness/contradiction sensitivity vs Gemini positive-phrasing/terse), contradiction linting, and promptfoo-based eval with rubrics mirroring the style axes.
- Two products from one substrate: the deployable skill library + a "prompt-smith" meta-skill that crafts prompts/skills per target model.
- Roadmap: spike by hand first (Phase 1), then format+emitter, model-aware rendering, eval harness, content, distribution.
- Craft corpus researched 2026-07-13 (repo `docs/research/2026-07-13-prompt-craft.md`): 2026 era shift = manual CoT dead on reasoning models, emphasis/caps dead (decision rules instead of absolutes), outcome contracts over step prescription, context-engineering frame; skill descriptions are trigger signals (third person, capability + use-when, front-loaded keywords, ≤1024 chars); evals-first skill development; CLAUDE.md <200 lines / Codex AGENTS.md 32KiB.
- Example corpus harvested 2026-07-13 (repo `docs/research/2026-07-13-example-corpus.md`): verbatim vendor policy blocks (persistence, context_gathering, self_reflection, scope, uncertainty, verbosity, long-context), two skill-description archetypes (+anti-triggers), complete example skills, real AGENTS.md/system-prompt excerpts, judge prompts, and next-tier model profiles (DeepSeek/Qwen/Grok/Llama need dedicated profiles — DeepSeek reasoning forbids system prompts & few-shot; profile the thinking MODE not the model). Key meta-rule: when vendor examples contradict vendor prose, trust the shipped examples (caps-for-invariants-only, imperative trigger-first descriptions, self-check tail sections).
