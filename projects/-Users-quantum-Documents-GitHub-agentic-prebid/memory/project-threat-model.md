Consolidated 2026-07-13 into `docs/design/threat-model.md` (register IR-57). Repo is source of truth. The user's framing question — *"not sure how to think about it in the era of agents"* — is the doc's spine.

**The reusable conceptual frame (this is the durable part).** A threat model in the era of agents is **NOT an enumeration of attacks across a perimeter** — it is **a statement of what holds no matter what the agents do.** Classic threat modeling (STRIDE, perimeter/data-flows) assumes the threat is an *outsider crossing a boundary* and that an *authenticated component is trusted*. Both die: the dangerous actor is **inside, authorized, autonomous** (our own agents + the LLM decide-seam), **non-deterministic + injectable** (can't tell compromised from honest by inspection), the real boundary is **economic not cryptographic** (capture = whose interest a signature serves, not who holds the key), and the **human backstop is gone** (machine-speed retries). So the adversary is stated ONCE as six capabilities — **A1 injection · A2 non-determinism · A3 capture · A4 confused-deputy · A5 autonomy · A6 dangerous-to-run** — every agent (OURS included) may exhibit all six; and the defense is **deterministic containment** (agents only *propose*, the kernel *disposes*; two-layer blast radius = isolation + Gate; money gates on WITNESSED facts not authored state). The honest output is a **bounded guarantee with named residuals, never "airtight."** Out-of-scope (named, not assumed away): principal key-compromise; a compromised rail/ad-server beyond witnessing; both-seat collusion (bounded not closed); a hypervisor 0-day. The **TC1–TC8** taxonomy (confused-deputy · injection/non-det · economic-capture · autonomous-double-effect · dangerous-to-run · yes-man-corroboration · re-aimable-signature · transport-double-effect) maps each class → the invariant/mechanism that contains it → the honest OPEN residual.

**The cross-seam hunt (the payoff — 3 FRESH diversified adversaries: money-path · authority/identity/model · runtime/lifecycle/transport).** They constructed multi-hop kill chains where **every hop passes its LOCAL guard but the chain is globally catastrophic** — invisible to the ~11 seam-by-seam passes. They **CONVERGED** from opposite ends:
- **HELD (positive):** **custody (INV-8) is airtight and composes** — no chain mints/moves money. **Money-correctness holds at the WITNESSED gate** — the settle gate reads `is_final`/N≥2 (sink facts), NOT the authored lifecycle, so **state-corruption cannot forge a settle** (proven by Y4: a CR1 lifecycle corruption reaches `→COMPLETED` but `→settle` FREEZES on I1). I11+PC4 compose to catch the booking-double-effect value-inflation seams miss. **The north-star claim survives every chain; a "fraud-proof" claim would not.**
- **OPEN — two SINGLE cross-cutting gaps (the whole value of the consolidation):** **GAP I — corroboration/authority *independence*:** the delivery+payment N≥2 quorums compose **SEQUENTIALLY (`min`, not sum)** — `finalized_amount` *becomes* `owed`, and payment corroborates *money-moved* not *owed-correct* → a corrupted `owed` flows through uncaught **+ un-clawbackable** (reversal re-consumes the same oracle, X1); authority-binding (I16/RT1/RT3/RT4) is a single layer down (X2 injected→config-bypass-I16→foreign ceiling; X3 compliance-cert *mints* a ceiling via the shared keyring; X4 witness∪beneficiary shell no seam owns; X7 scope-never-gated — delivery-oracle and authority each assumed the OTHER gated it); and **HITL is model-STEERABLE via persuasion** (X5 — the model authors the rationale that reaches the human; the untrusted-out scan catches exfil NOT persuasion → re-opens EVERY "gated-OFF-meanwhile" posture at once). **GAP II — serve-*authorization*:** **CR1 is a GENERAL reactor gap, not T15-local** (`T7 →LIVE`/`→COMPLETED` too; freeze-wins is money-path-only, the drain re-checks only legal-edge) → a corrupt constructive edge serves **real unapproved/expired-inventory impressions that then settle LEGITIMATELY** (Y1, no catcher). **The kernel validates that delivery HAPPENED, never that serving was AUTHORIZED** — the sharpest new honest boundary.

**Genuinely NEW (vs. sharper-statement-of-known):** most OPEN chains bottom out in already-gated-OFF residuals (economic independence RA1/RA5/RA-BENE/MB5, authority RT1/RT3/RT4, I16-coupling) — so not new *breaks*; the value is the **cross-seam framing** (two single gaps composition doesn't close). The genuinely new: **(1) CR1 is general** (T7 too — actionable engine fix, IR-57a); **(2) the serve-authorization boundary as a named gap** (delivery-happened ≠ serving-authorized, Y1 no catcher); **(3) the witness∪beneficiary disjointness is a cross-seam invariant NO seam owns** (+ the sub-processor bucket one layer deeper, RA6c); **(4) HITL model-steerability via persuasion**; **(5) the sequential-quorum `min`-not-sum + un-clawbackable framing.** Deltas IR-57(a–e).

**The method lesson (reusable):** **seam-by-seam verification is itself blind to cross-seam composition** — a chain individually-legal-at-each-hop but globally catastrophic passes every seam pass. Hunt it with **fresh, diversified** adversaries (by surface, not identical); if the finding is real they CONVERGE (both money-path and authority hunters independently reached "the corroboration/authority-independence layer is one gap, not isolated caveats"). This extends [[feedback-mirror-prose-not-enforcement]] — the seam-red-team is a "mirror" that verifies each seam's prose-as-enforcement but misses the *composition*.

**Strategic value:** the consolidation confirms the [[project-real-money-first]] north star is honestly calibrated (POSITION §3.8 sharpened per-threat-class + the two new boundaries). The deliverable is the *honest boundary*, not a false airtight.
